The short version

Date Versioning is a static website for a versioning standard. It has no accounts, forms, analytics, tracking or advertising, sets no cookies, and collects no personal data about you.

Who is responsible

Hosting

This site is hosted on GitHub Pages. GitHub may process your IP address and browser details to deliver the site and protect it from abuse, under GitHub's privacy statement. We don't receive or keep those logs.

External requests the site makes

Everything on the site (styles, scripts, icons and the specification) is served from this site, and it uses your system's fonts. The only request to another host is:

  • https://global.media.stux.group/logo.png, the Stux.Group logo in the footer, served by Stux.Group. It is a plain image request: it carries no cookies and nothing that identifies you beyond what any web request includes (your IP address and browser details).

The two tools on the home page (Next version and Validate) run entirely in your browser. What you type into them is never sent anywhere. The README badge snippet is text for you to copy; the badge it describes is only requested by your README, not by this site.

Browser storage

None. The site uses no cookies, localStorage, sessionStorage or similar.

Your rights

Under the UK GDPR you can ask what personal data we hold about you. For this site the answer is none, but you're welcome to ask at legal@stux.group.
